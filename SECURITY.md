# Security policy

TrustLight is a scam checker, so its own security matters a lot to us. Thank you for helping keep it safe.

## Reporting a security problem

Please report security problems **privately**, not in a public issue:

1. Go to the [Security tab](https://github.com/sathwikraibs/StaySafe/security) of this repository.
2. Choose **Report a vulnerability** and describe the problem: what you found, where, and how to reproduce it.

Please include, if you can:

- the page or API address involved
- the steps to reproduce it
- what an attacker could do with it

Please do not include real people's personal details, and do not test against other people's data.

## What happens next

- We aim to reply within **7 days**.
- We will keep you updated while we fix it, and we aim to fix serious problems within **30 days**.
- Once it is fixed we will publish a short note in the Security tab, and thank you by name if you would like.

## In scope

- The website: https://staysafe-tool.vercel.app
- The backend API and the code in this repository

## Out of scope

- Scam links or messages that TrustLight gets wrong. Those are welcome too, but as a normal [issue](https://github.com/sathwikraibs/StaySafe/issues), not a security report.
- Problems in outside services TrustLight uses (please report those to that service).
- Attacks that need a rooted or already-infected phone, denial-of-service, or spam.

## Supported versions

Only the current live version is supported. Fixes are released straight to the live site.
